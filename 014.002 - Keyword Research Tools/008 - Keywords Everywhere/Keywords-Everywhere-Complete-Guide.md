## Overview

**Keywords Everywhere** is a browser-based keyword research extension that overlays SEO metrics directly onto search engine results pages (SERPs) and 20+ platforms including Google, YouTube, Amazon, Bing, eBay, and Etsy.

### Key Value Proposition
- **In-browser data**: No tab-switching between research tools
- **Real-time insights**: See metrics as you naturally browse
- **Multi-platform**: Works across Google, YouTube, Amazon, and 15+ other sites
- **Credit-based pricing**: Pay-per-use model, no monthly subscriptions
- **1.6M+ active users**: Industry-proven tool since 2016

### Version History
- **2016**: Launched as free Chrome extension
- **2019**: Shifted to freemium model (API cost coverage)
- **2025**: Added ChatGPT fanout queries, Google Maps metrics, Keyword Keg integration

## Installation & Setup

### Browser Compatibility
- **Chrome**: Primary platform (Chrome Web Store)
- **Firefox**: Full feature parity
- **Edge**: Via Chrome extension compatibility
- **Mobile**: Firefox Android only (limited features)

### Installation Steps

1. **Add Extension**
   ```
   Chrome Web Store → Search "Keywords Everywhere" → Add to Chrome
   Firefox Add-ons → Search "Keywords Everywhere" → Add to Firefox
   ```

2. **Create Account**
   - Visit keywordseverywhere.com
   - Register with email
   - Verify account

3. **Generate API Key**
   - Dashboard → API Settings
   - Copy API key
   - Paste in extension settings (right-click extension icon → Options)

4. **Purchase Credits** (for paid features)
   - Dashboard → Buy Credits
   - Select package
   - Payment via PayPal, Stripe, Paddle.net

5. **Configure Settings**
   - Enable/disable specific platforms
   - Choose metric displays
   - Set default country/language
   - Toggle widget visibility

## Data Metrics Explained

### 1. Search Volume
**Definition**: Average monthly searches (last 12 months)
**Source**: Google Trends data + proprietary algorithms

**Interpretation**:
```
Volume Ranges:
- 0-100: Micro-niche (long-tail gold if relevant)
- 100-1,000: Niche opportunity
- 1,000-10,000: Good target for small-medium sites
- 10,000-100,000: Competitive, requires authority
- 100,000+: Highly competitive, long-term target

Example Strategy:
Target: 15 keywords with 2,000-5,000 vol = 30,000-75,000 potential monthly traffic
Easier than 1 keyword with 50,000 vol
```

---

### 2. CPC (Cost Per Click)
**Definition**: Average advertiser bid in Google Ads
**Unit**: USD (or local currency)

**SEO Value of CPC**:
```
High CPC ($10+) = High commercial intent
- "car insurance quotes" - $54 CPC
- "injury lawyer" - $110 CPC
- "merchant services" - $38 CPC

Medium CPC ($1-10) = Moderate intent
- "best running shoes" - $3.20 CPC
- "yoga mat" - $1.80 CPC

Low CPC ($0-1) = Informational
- "what is yoga" - $0.30 CPC
- "history of coffee" - $0.15 CPC

Strategy:
- Target high CPC keywords for affiliate/lead gen
- Balance with low-comp, low-CPC for traffic volume
```

---

### 3. Competition Score (0-100)
**Definition**: Difficulty to rank organically
**Factors**: Domain authority of ranking pages, backlink profiles, content quality

**Ranges**:
```
0-30 (Easy):
- New sites can rank
- Low-authority domains in top 10
- Example: "best yoga mat for hot yoga"

31-60 (Medium):
- Requires quality content + some backlinks
- Mix of medium-authority domains
- Example: "yoga mat"

61-80 (Hard):
- Need established authority
- Multiple high-DA sites ranking
- Example: "best yoga mats"

81-100 (Very Hard):
- Requires significant resources
- Top brands dominate
- Example: "yoga" (just the keyword)

Site Age Strategy:
- New site (0-6 months): Target 0-40 comp
- Growing site (6-18 months): Target 30-60 comp
- Established site (18+ months): Target 50-80 comp
```

**Factors**:

## Limitations & Workarounds

### Current Limitations

#### 1. Credit Expiration
**Issue**: Credits expire after 365 days
**Workaround**:
- Buy smaller packages more frequently
- Set calendar reminder at 11 months
- Use credits before expiration

#### 2. Mobile Limitations
**Issue**: Limited mobile support (Firefox Android only)
**Workaround**:
- Use mobile for validation only
- Do main research on desktop
- Remote desktop apps for mobile research

#### 3. No Backlink Analysis
**Issue**: Doesn't show backlink data
**Solution**:
- Pair with Ahrefs/SEMrush for backlinks
- Use free Moz metrics (included in Keywords Everywhere)
- Focus Keywords Everywhere on keyword research only

#### 4. Platform-Specific Volume
**Issue**: Volumes are Google-based, may differ on YouTube/Amazon
**Workaround**:
- Use platform-specific tools for validation
- Keywords Everywhere shows trends, not absolute truth
- Cross-reference critical decisions

#### 5. Lag Behind Real-Time
**Issue**: Data updated periodically, not real-time
**Impact**: Breaking news keywords may show low volume
**Workaround**:
- Use Google Trends for real-time spikes
- Keywords Everywhere for established keywords

### Common Issues & Solutions

#### Issue: Extension Not Displaying Data
```
Solutions:
1. Check API key is entered correctly
2. Verify credits remaining (Dashboard)
3. Clear browser cache
4. Disable conflicting extensions
5. Check if platform is supported
6. Ensure extension is updated
```

#### Issue: Credits Depleting Too Fast
```
Analysis:
- Check if auto-widgets are enabled (bulk drain)
- Review search behavior (random searches waste credits)
- Multiple devices logged in?

Solutions:
1. Disable auto-load for related keywords
2. Turn off extension when not researching
3. Log out unused devices
4. Export data, work offline
```

#### Issue: Volumes Don't Match Other Tools
```
Context:
- Different tools use different data sources
- Keywords Everywhere: Google Trends + proprietary
- SEMrush: Clickstream data
- Ahrefs: Third-party providers

Approach:
- Use Keywords Everywhere as directional guidance
- Cross-check critical keywords on multiple tools
- Trust trends more than absolute numbers
```
