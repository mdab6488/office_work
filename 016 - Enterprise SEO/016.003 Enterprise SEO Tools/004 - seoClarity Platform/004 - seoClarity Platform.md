**Real-World Example: Global Software Company**

```
Client: Enterprise SaaS Company
Sites: 18 regional websites, 12 languages
Pages: 487,000 total pages across all sites

Clarity Audits Configuration:

Audit Scope:
├── Weekly full crawls: All 18 sites
├── Daily priority page checks: Top 10,000 pages
├── Mobile-first indexing monitoring: All pages
└── Page speed monitoring: 50,000 key pages

Week 1 Audit Results - Critical Findings:

GLOBAL ISSUES DETECTED:

1. Hreflang Implementation Errors (CRITICAL)
   
   Issue: 34,000 pages with incorrect hreflang tags
   Impact: Search engines can't properly serve regional content
   
   Example Error:
   Page: /en-us/pricing
   Current hreflang tags:
   ```html
   <link rel="alternate" hreflang="en" href="/en-us/pricing"/>
   <link rel="alternate" hreflang="de" href="/de-de/pricing"/>
   <link rel="alternate" hreflang="fr" href="/fr-fr/pricing"/>
   ```
   
   Problem: Missing x-default tag
   Problem: Incomplete tag implementation (12 languages, only 3 tagged)
   Problem: Some tags pointing to 404 pages
   
   Correct Implementation:
   ```html
   <link rel="alternate" hreflang="x-default" href="/en/pricing"/>
   <link rel="alternate" hreflang="en-US" href="/en-us/pricing"/>
   <link rel="alternate" hreflang="en-GB" href="/en-gb/pricing"/>
   <link rel="alternate" hreflang="de-DE" href="/de-de/pricing"/>
   <link rel="alternate" hreflang="de-AT" href="/de-at/pricing"/>
   <link rel="alternate" hreflang="de-CH" href="/de-ch/pricing"/>
   <link rel="alternate" hreflang="fr-FR" href="/fr-fr/pricing"/>
