
## Measuring Enterprise SEO Success

### Key Performance Indicators (KPIs)

#### Business KPIs
```
Revenue Metrics
├── Organic revenue
├── Revenue per session
├── Conversion rate
└── Average order value

Traffic Metrics
├── Total organic sessions
├── New vs returning visitors
├── Traffic by page type
└── Traffic by device
```

#### SEO KPIs
```
Visibility Metrics
├── Keyword rankings (Top 3, Top 10)
├── Share of voice
├── Featured snippets owned
└── SERP feature wins

Technical Metrics
├── Crawl efficiency
├── Indexation rate
├── Core Web Vitals
├── Site speed
└── Mobile usability
```

#### Operational KPIs
```
Efficiency Metrics
├── Pages optimized per week
├── Time to implement changes
├── SEO ticket completion rate
└── SLA compliance

Quality Metrics
├── Average SEO score
├── Content quality rating
├── Technical health score
└── Stakeholder satisfaction
```
