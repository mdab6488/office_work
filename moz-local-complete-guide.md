## Introduction

Moz Local is a local SEO management platform designed to help businesses manage their online presence across multiple directories, search engines, and review sites. It automates the process of creating, updating, and monitoring local business listings while ensuring NAP (Name, Address, Phone) consistency across the web.

**Primary Purpose:** Centralize local listing management to improve local search visibility, drive foot traffic, and maintain accurate business information across the internet.

---

## What is Moz Local

### Definition
Moz Local is a citation management and local listing distribution service that helps businesses:
- Distribute accurate business information to major search engines and directories
- Monitor and manage online reviews
- Track listing accuracy and visibility
- Suppress duplicate listings
- Analyze local search performance

### Who Needs Moz Local

**Perfect For:**
- Multi-location businesses (franchises, retail chains)
- Local service providers (law firms, medical practices, contractors)
- Restaurants and hospitality businesses
- Real estate agencies
- Local retailers
- SEO agencies managing local clients

**Less Suitable For:**
- Pure e-commerce businesses without physical locations
- National brands without local presence
- Businesses targeting only global audiences

## How Moz Local Works

### The Technical Process

#### Step 1: Initial Audit
```
User Input → Moz Scans Web → Identifies Existing Listings → Reports Discrepancies
```

**What Happens:**
- Moz crawls 100+ directories for your business name and address
- Identifies correct listings, duplicates, and inaccurate information
- Generates a "Listing Score" (0-100) showing current accuracy

#### Step 2: Data Aggregator Submission
```
Your Data → Moz Local → Data Aggregators → 1000+ Downstream Sites
```

**Timeline:**
- **Data Aggregators:** 2-4 weeks for initial distribution
- **Direct Publishers:** 1-2 weeks
- **Downstream Sites:** 4-12 weeks for full propagation

#### Step 3: Continuous Monitoring
```
Daily Scans → Detect Changes → Auto-Update Where Possible → Alert User
```

**Monitoring Frequency:**
- Critical sites (Google, Bing): Daily
- Major directories: Weekly
- Smaller sites: Bi-weekly

#### Step 4: Duplicate Management
```
Detect Duplicate → Verify Ownership → Submit Suppression Request → Monitor Removal
```

## Getting Started

### Prerequisites

**Required Information:**
- ✅ Exact business name (must match legal name)
- ✅ Complete street address
- ✅ Local phone number (not toll-free)
- ✅ Primary business category
- ✅ Website URL
- ✅ Business hours

**Recommended:**
- High-quality logo (1000x1000px minimum)
- Business description (up to 750 characters)
- Photos (interior, exterior, products/services)
- Additional phone numbers
- Payment methods accepted
- Parking information
- Service areas (for service businesses)

### Setup Process

#### Step 1: Create Account
```
1. Visit moz.com/local
2. Sign up with email
3. Choose plan (Essential, Preferred, Elite)
4. Enter billing information
```

#### Step 2: Add Your Business
```
1. Enter business name
2. Input complete address
3. Add phone number
4. Select primary category (choose wisely - this affects where you appear)
5. Add website URL
```

**Category Selection Best Practices:**
- Choose the MOST SPECIFIC category that applies
- Avoid generic categories like "Business" or "Company"
- Research what competitors use
- Consider category hierarchy

**Example:**
- ❌ Bad: "Restaurant"
- ✅ Good: "Italian Restaurant"
- ✅ Better: "Neapolitan Pizza Restaurant"

#### Step 3: Complete Business Profile
```
1. Add extended description
2. Upload photos (minimum 5, recommend 10+)
3. Enter business hours (including special hours for holidays)
4. Add additional details:
   - Payment methods
   - Languages spoken
   - Parking info
   - WiFi availability
   - Accessibility features
```

#### Step 4: Verify Existing Listings
```
1. Moz presents listings it found
2. Confirm which are yours
3. Flag duplicates for suppression
4. Correct any inaccurate information
```

#### Step 5: Initiate Distribution
```
1. Review all information for accuracy
2. Click "Distribute Listings"
3. Moz begins submission process
4. Monitor progress in dashboard
```

## Listing Management

### NAP Consistency

**The Golden Rule:**
Your Name, Address, and Phone must be IDENTICAL across all platforms.

**Correct Format Example:**
```
Business Name: Joe's Pizza & Italian Kitchen
Address: 123 Main Street, Suite 4B, Austin, TX 78701
Phone: (512) 555-0100
```

**Common NAP Mistakes:**

| ❌ Inconsistent | ✅ Consistent |
|----------------|--------------|
| Joe's Pizza | Joe's Pizza & Italian Kitchen |
| Joes Pizza | Joe's Pizza & Italian Kitchen |
| Joe's Pizza and Italian Kitchen | Joe's Pizza & Italian Kitchen |
| 123 Main St | 123 Main Street |
| 123 Main Street #4B | 123 Main Street, Suite 4B |
| 512-555-0100 | (512) 555-0100 |
| 5125550100 | (512) 555-0100 |

**Why This Matters:**
- Search engines use NAP to verify legitimacy
- Inconsistencies split citation value
- Can cause duplicate listings
- Confuses customers

### Bulk Updates

**When You Need to Update:**
- Moving locations
- Changing phone systems
- Rebranding
- Adjusting business hours seasonally
- Adding new services

**Process:**
```
1. Update in Moz Local dashboard
2. Changes propagate to data aggregators (2-4 weeks)
3. Data aggregators update downstream sites (4-12 weeks)
4. Monitor completion in Distribution Status report
```

**Pro Tip:** For urgent changes (like emergency hours), update Google Business Profile and Facebook directly while Moz propagates to other sites.

## Duplicate Detection & Suppression

### Why Duplicates Happen

**Common Causes:**
1. **Previous owner listings** - Old business listings persist
2. **Data aggregator conflicts** - Different aggregators have different data
3. **Spelling variations** - "St" vs "Street", "&" vs "and"
4. **User-generated listings** - Platforms like Yelp allow user creation
5. **Franchise/chain confusion** - Corporate vs individual location listings
6. **Historical addresses** - Old location listings remain active

### The Duplicate Problem

**Impact on SEO:**
- Dilutes citation authority (splits link equity)
- Confuses search engines about "real" location
- Can cause ranking penalties
- Splits review ratings across multiple listings

**Real-World Example:**
```
Scenario: Pizza restaurant has 3 Google listings

Listing A: 4.5 stars (30 reviews)
Listing B: 3.8 stars (12 reviews)
Listing C: 4.2 stars (8 reviews)

Problem: Customers see different ratings depending on which listing they find
Solution: Suppress B and C, consolidate all reviews to Listing A
Result: 4.3 stars (50 reviews) - stronger signal
```

### Detection Process

**Moz Local Identifies:**
- Exact duplicates (same NAP)
- Near duplicates (similar NAP)
- Variations (abbreviations, formatting differences)
- Outdated listings (old addresses)

**Dashboard View:**
```
Listing Status Report:
✅ Verified Listings: 45
⚠️  Possible Duplicates: 12
❌ Inaccurate Listings: 8
🔄 Pending Updates: 23
```

### Suppression Process

**Automatic Suppression (Works On):**
- Data aggregator-sourced duplicates
- Moz partner network listings
- Some directory submissions

**Manual Suppression Required:**
- User-generated listings (Yelp, Google)
- Claimed listings by others
- Some independent directories

**Step-by-Step Suppression:**

#### For Google Business Profile Duplicates:
```
1. Identify duplicate listing in Moz Local
2. Claim the duplicate in Google Business Profile
3. Request removal through Google Business Profile help
4. Provide documentation if needed
5. Wait 2-4 weeks for removal
6. Mark as suppressed in Moz Local
```

#### For Data Aggregator Duplicates:
```
1. Flag duplicate in Moz Local dashboard
2. Moz submits suppression request to aggregators
3. Aggregators remove from their database
4. Changes propagate downstream (4-12 weeks)
5. Monitor removal status in Moz dashboard
```

**Suppression Timeline:**
- Data aggregators: 2-4 weeks
- Direct publishers: 1-4 weeks (if you control the listing)
- Downstream sites: 6-12 weeks
- Stubborn duplicates: May require legal documentation

**Alert System:**

### Review Response Management

**Best Practices:**

#### For Positive Reviews (4-5 Stars):
```
Template:
"Thank you [Name] for the wonderful review! We're thrilled you enjoyed 
[specific detail they mentioned]. We look forward to serving you again soon!"

Example:
"Thank you John for the wonderful review! We're thrilled you enjoyed 
our Neapolitan margherita pizza. We look forward to serving you again soon!"
```

#### For Neutral Reviews (3 Stars):
```
Template:
"Thank you [Name] for your feedback. We appreciate you noting [positive], 
and we're working to improve [issue mentioned]. Please give us another 
chance to provide a better experience!"

Example:
"Thank you Sarah for your feedback. We appreciate you noting our great food, 
and we're working to improve our service speed during peak hours. Please give 
us another chance to provide a better experience!"
```

#### For Negative Reviews (1-2 Stars):
```
Template:
"We apologize for your experience, [Name]. This doesn't meet our standards. 
Please contact us directly at [phone/email] so we can make this right and 
resolve [specific issue]."

Example:
"We apologize for your experience, Mike. This doesn't meet our standards. 
Please contact us directly at (512) 555-0100 so we can make this right and 
resolve the incorrect order issue."
```

**Response Timing:**
- Negative reviews: Within 24 hours
- Neutral reviews: Within 48 hours
- Positive reviews: Within 72 hours

### Review Generation Strategies

**Ethical Methods:**

1. **Post-Purchase Email Campaign**
```
Subject: How was your experience at [Business Name]?

Hi [Customer],

Thank you for choosing [Business Name]! We'd love to hear about your 
recent visit on [date].

Would you mind sharing your experience?
[Link to Google Review]

Your feedback helps us improve and helps others discover us.

Thank you!
[Your Name]
```

2. **In-Store Signage**
```
"Loved your experience? 
Please review us on Google!"
[QR Code to review page]
```

3. **Receipt Integration**
```
"Rate your experience:
google.com/review/yourbusiness
Your feedback matters!"
```

4. **SMS Follow-Up** (with permission)
```
"Hi [Name], thanks for visiting [Business]! Mind leaving us a 
quick review? [short link] Reply STOP to opt out."
```

**What NOT to Do:**
- ❌ Offer incentives for reviews (violates Google policies)
- ❌ Write fake reviews
- ❌ Only ask satisfied customers
- ❌ Gate review requests (ask only after positive feedback)
- ❌ Review swapping with other businesses

## Best Practices

### NAP Optimization

**The Perfect NAP Format:**

```
Business Name: [Exactly as registered, including legal designation if used]
Address: [Full street address with suite/unit], [City], [State] [ZIP]
Phone: ([Area Code]) [3-digit]-[4-digit]

Example:
Smith & Associates Legal Group, PLLC
1500 Broadway Street, Suite 200, Nashville, TN 37203
(615) 555-0199
```

**Common Format Decisions:**

| Element | Recommendation | Example |
|---------|---------------|---------|
| Street | Spell out "Street", "Avenue" | Main Street (not Main St) |
| Suite/Unit | Use comma, spell out | Suite 4B (not Ste 4B) |
| Phone | Use parentheses and dash | (615) 555-0199 |
| State | Use postal code | TN (not Tennessee) |
| ZIP | 5-digit unless specific area needs ZIP+4 | 37203 |

## Common Issues & Solutions

### Issue 1: Slow Distribution

**Symptom:** Listings not appearing after 4-6 weeks

**Diagnosis:**
```
Check Distribution Status:
- Are data aggregators showing "Submitted"?
- Any error messages?
- Have you verified ownership where required?
```

**Solutions:**

1. **Manual Verification Needed**
```
Problem: Platform requires ownership verification
Examples: Google (postcard), Yelp (phone call)

Solution:
- Complete verification process
- Check for verification requests in email
- Call platform support if needed
```

2. **NAP Mismatch**
```
Problem: Platform has different NAP and won't accept update

Solution:
- Verify exact NAP format platform expects
- May need to claim and update manually
- Ensure consistency with public records
```

3. **Category Issues**
```
Problem: Category you selected not available on platform

Solution:
- Research platform's category options
- Choose closest alternative
- May need platform-specific optimization
```

### Issue 2: Listings Won't Update

**Symptom:** Changes not propagating to directories

**Diagnosis:**
```
Timeline Check:
- Data aggregators: 2-4 weeks normal
- Direct publishers: 1-2 weeks normal
- Downstream sites: 4-12 weeks normal

If beyond these timeframes, investigate further.
```

**Solutions:**

1. **Claimed by Someone Else**
```
Problem: Another user/company controls the listing

Solution:
- Verify business ownership with platform
- Provide business documentation
- Request access transfer
- May need legal documentation for disputes
```

2. **Incorrect Claim Process**
```
Problem: You claimed wrong listing or didn't complete claim

Solution:
- Review claimed listings in each platform
- Complete any pending verification steps
- May need to unclaim and reclaim correctly
```

3. **Platform-Specific Policies**
```
Problem: Platform has unique requirements

Example: Yelp
- Won't accept info changes without verification
- Has specific photo requirements
- Limits description length differently

Solution:
- Review platform's guidelines
- Update according to their requirements
- Contact their support if needed
```

### Issue 3: Duplicate Listings Persist

**Symptom:** Duplicates flagged but not removed after 8+ weeks

**Diagnosis:**
```
Check Duplicate Source:
- Data aggregator duplicate? (Can suppress)
- User-generated duplicate? (Harder to remove)
- Claimed by someone else? (Requires verification)
```

**Solutions:**

1. **User-Generated Duplicates (Google, Yelp)**
```
Process:
1. Claim both listings (if you can)
2. Request merge/removal through platform
3. Provide documentation:
   - Business license
   - Utility bills
   - Tax documents
   - Website domain ownership
4. Follow up weekly
5. Timeline: 2-8 weeks typical
```

2. **Unclaimed Data Aggregator Duplicates**
```
Process:
1. Verify Moz submitted suppression request
2. Contact aggregator directly:
   - Acxiom: datagovernance@acxiom.com
   - Localeze: support@localeze.com
   - Factual: support@factual.com
3. Provide business documentation
4. Reference Moz suppression request
```

3. **Stubborn Duplicates**
```
Nuclear Option:
1. Document all attempts to remove
2. Consider cease & desist letter (legal)
3. File complaint with platform
4. May need to accept presence and outrank it
```

### Issue 4: Review Issues

**Problem 1: Fake Negative Review**

**Solution:**
```
1. Flag review on platform:
   - Google: "Report review" → Select reason
   - Yelp: "Report review" → Explain situation
   - Facebook: Report as false

2. Provide evidence review is fake:
   - No transaction record
   - Date inconsistencies
   - Competitor patterns
   - Offensive language

3. Respond publicly (in case not removed):
   "We have no record of serving [reviewer name] on [date claimed]. 
   We've reported this review as it doesn't reflect a genuine customer 
   experience. We welcome all feedback from actual customers."

4. Monitor for removal (1-4 weeks typical)
```

**Problem 2: Can't Respond to Reviews**

**Solution:**
```
Verification Required:
- Ensure you've claimed listing
- Verify business ownership
- Check platform requirements
- Some platforms require specific verification steps

Platform-Specific:
Google: Must claim Google Business Profile first
Yelp: Must verify business ownership
Facebook: Must be page admin
```

**Problem 3: Old Reviews from Previous Owner**

**Solution:**
```
1. Claim the listing
2. Contact platform support
3. Provide proof of ownership change:
   - Sale documents
   - New business license
   - Documentation of name change

4. Request review reset (not always granted)
5. Alternative: Address in your profile
   "Under new ownership since [date]"
```

### Issue 5: Low Listing Score Stuck

**Symptom:** Score won't improve beyond 75-80%

**Diagnosis:**
```
Review Moz Local Breakdown:
- Which categories are dragging score down?
- Are there platforms you can't access?
- Profile completeness issues?
```

**Solutions:**

1. **Profile Completeness**
```
Add Missing Elements:
□ Business description (250+ words)
□ 10+ high-quality photos
□ All business hours (including special hours)
□ All applicable attributes
□ Service areas (if applicable)
□ Payment methods
□ Parking information
□ Website URL with HTTPS
```

2. **Stubborn Inaccuracies**
```
Manual Override:
1. Identify platforms with wrong info
2. Claim those platforms directly
3. Update manually (don't wait for Moz)
4. Document in Moz why manual update needed
```

3. **Inaccessible Platforms**
```
Some directories may be:
- Paid directories (upgrade needed)
- Industry-specific (join association)
- Closed to new submissions

Focus on:
- Platforms you CAN control
- High-impact sites (Google, Bing, Yelp)
- 90%+ on accessible platforms is excellent
```
