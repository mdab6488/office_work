
## Shopify SEO Checklist

### Pre-Launch Checklist

**Theme & Technical Setup**
```
□ Choose SEO-optimized theme (Dawn, Turbo, Impulse)
□ Install SSL certificate (included with Shopify)
□ Set up 301 redirects if migrating
□ Configure Google Search Console
□ Set up Google Analytics 4
□ Install essential SEO app (Plug in SEO or SEO Manager)
□ Enable Google Merchant Center integration
```

**On-Page Optimization**
```
□ Optimize homepage meta title & description
□ Create meta templates for products & collections
□ Add alt text to all images
□ Implement breadcrumb navigation
□ Set up proper heading hierarchy (H1, H2, H3)
□ Add FAQ section to key pages
□ Create About Us & Contact pages with rich content
□ Write unique product descriptions (300+ words for top products)
```

**Technical SEO**
```
□ Implement schema markup (Product, Organization, Breadcrumb)
□ Optimize images (WebP format, compression, lazy loading)
□ Ensure mobile responsiveness
□ Check Core Web Vitals scores
□ Set up XML sitemap (automatic in Shopify)
□ Configure robots.txt (automatic in Shopify)
□ Add canonical tags (automatic in Shopify)
□ Implement 404 error page with helpful navigation
```

---

### Ongoing SEO Tasks

**Weekly**
```
□ Check Google Search Console for errors
□ Monitor site speed (PageSpeed Insights)
□ Review new 404 errors and create redirects
□ Check for broken links
□ Publish 1 blog post (800+ words)
□ Add new products with optimized content
```

**Monthly**
```
□ Run full SEO audit with Plug in SEO
□ Review top landing pages and optimize
□ Analyze keyword rankings
□ Update meta descriptions for top pages
□ Check for duplicate content issues
□ Review and remove underperforming apps
□ Analyze Core Web Vitals reports
□ Update FAQ content based on customer questions
```

**Quarterly**
```
□ Comprehensive technical SEO audit
□ Content gap analysis (find new keyword opportunities)
□ Backlink profile review
□ Competitor analysis
□ Review and update pillar content
□ Refresh old blog posts with new information
□ Mobile usability testing
□ Schema markup validation
```
